# Nexu4isha Flipbook

A little birthday flipbook website. The first image is the cover, and each following image is a page you can flip through by clicking, using the arrow keys, or swiping on mobile.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
